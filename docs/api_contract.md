# API contract: Series 76 Technical Assistant

Source of truth in code: `backend/app/api/schemas.py`. Interactive OpenAPI at `http://localhost:8001/docs`.

## Conventions
- JSON, everything under `/api`. UUID v4 ids. ISO-8601 dates in UTC.
- **Auth**: `Authorization: Bearer <access_token>` on every endpoint except `POST /api/auth/login` and `GET /api/health`.
  Each user sees and uses only their own conversations.
- **Errors** (single format):
  ```json
  { "error": { "code": "SESSION_NOT_FOUND", "message": "Session not found" } }
  ```
- **Technical numbers**: they always come from the database (`products`). The `answer` text is generated by the
  agent using only data returned by the tools, and is checked numerically before it is returned.

## Endpoints

| | Method | Path | Auth | Purpose |
|---|---|---|---|---|
| **Required** | POST | `/api/conversation` | ✅ | Send a query; creates or continues a conversation |
| Suggested | GET | `/api/sessions` | ✅ | List of the user's conversations |
| Suggested | GET | `/api/sessions/{session_id}/messages` | ✅ | History to resume a conversation |
| Extra | DELETE | `/api/sessions/{session_id}` | ✅ | Delete a conversation (mobile "Delete Chat") |
| Suggested (login) | POST | `/api/auth/login` | — | Email + password → token |
| Extra | GET | `/api/auth/me` | ✅ | Validate a saved token (app startup) |
| Extra (debug) | GET | `/api/debug/sessions` | ✅ admin | Every user's conversations, each with its owner |
| Extra (debug) | GET | `/api/debug/sessions/{session_id}/messages` | ✅ admin | History of any user's conversation |
| Extra (debug) | GET | `/api/messages/{message_id}/debug` | ✅ admin | Trace of an answer (any user) for the debug screen |
| Extra | GET | `/api/health` | — | Service and DB status |

Changes compared with the assessment's suggestion (justified in the README):
- `/api/sessions` returns `{items, total}` and accepts `limit`/`offset` (pagination).
- `/api/sessions/{id}/messages` includes `products` and `suggestions` so the app can re-render the history the same way.
- Debug is a **separate** endpoint: the chat response never carries internal data (tool names, parameters).
- `client_message_id` in `POST /api/conversation`: idempotency for retries with intermittent connectivity.
- `/api/auth/me` and `/api/health` added.
- `DELETE /api/sessions/{id}` added (the app's "Delete Chat" action).
- Roles: `user.is_admin`. Only administrators can use the debug endpoints (the app shows the Debug button only to them);
  they see **every user's** conversations and traces, grouped by user in the app.

## POST /api/auth/login
```json
// request
{ "email": "ana@konecto.test", "password": "Series76!demo" }
// 200
{
  "access_token": "eyJhbGciOi...",
  "token_type": "bearer",
  "expires_in": 86400,
  "user": { "id": "7b0e…", "email": "ana@konecto.test", "name": "Ana Torres", "is_admin": true }
}
```
Errors: `401 INVALID_CREDENTIALS`, `422 VALIDATION_ERROR`.

## GET /api/auth/me
`200` → `{ "id", "email", "name", "is_admin" }` (the app refreshes the role with it at startup) · `401 UNAUTHORIZED` if the token is missing, invalid or expired.

## POST /api/conversation
```json
// request
{
  "session_id": null,                       // optional: omitted → new conversation
  "query": "What is the torque of 761A00-11300000/A?",
  "client_message_id": "3f6c…"              // optional: idempotency
}
```
- `session_id` omitted → a new conversation is created and its id is returned.
- `session_id` of the user's own conversation → it continues (multi-turn: "and how much power does it draw?" resolves the part from context).
- `session_id` that doesn't exist → it is created with that id (the app can create conversations offline).
- `session_id` belonging to another user → `404 SESSION_NOT_FOUND`.
- `client_message_id` already processed → the stored answer is returned without calling the agent again.

```json
// 200
{
  "session_id": "c1d2…",
  "message_id": "9a8b…",
  "created_at": "2026-11-03T18:20:11Z",
  "answer": "The **761A00-11300000/A** (weatherproof, 110V single phase) delivers **700 in-lbs (80 Nm)** in on/off service and **580 in-lbs (65 Nm)** in modulating service.",
  "status": "answered",
  "products": [
    {
      "part_number": "761A00-11300000/A",
      "role": "match",
      "enclosure": "weatherproof",
      "certifications": ["CSA", "CE", "UKCA"],
      "csa_certified": true,
      "power_supply": { "voltage_v": 110, "phase": 1, "current_type": "ac", "label": "110V single phase AC" },
      "motor_power_w": 15,
      "data_available": true,
      "ratings": [
        { "service_type": "on_off", "torque_inlb": 700, "torque_nm": 80, "duty_cycle_pct": 40, "cycles_per_hour": 36, "starts_per_hour": null },
        { "service_type": "modulating", "torque_inlb": 580, "torque_nm": 65, "duty_cycle_pct": 40, "cycles_per_hour": null, "starts_per_hour": 960 }
      ],
      "electrical": [
        { "frequency_hz": 60, "operating_speed_s": 17, "fla_a": 1.2, "lra_a": 1.4 },
        { "frequency_hz": 50, "operating_speed_s": 20, "fla_a": 1.1, "lra_a": 1.3 }
      ],
      "source": { "table": "WEATHERPROOF - CSA, CE, & UKCA | 110V - Single Phase Power", "page": 1 }
    }
  ],
  "suggestions": []
}
```

### `status`
| Value | When | `products` / `suggestions` |
|---|---|---|
| `answered` | Answer with data | products with `role: match` |
| `clarification_needed` | Ambiguous question, partial ID with several matches, or missing requirements | `suggestions` = options |
| `not_found` | The part number does not exist (typo or invalid) | `suggestions` = "did you mean…?" |
| `no_match` | No model meets the requirements | products with `role: alternative` (closest ones), if any |
| `data_unavailable` | The model exists, but the datasheet has no data (N/A) | product with `data_available: false` |
| `out_of_scope` | Unrelated to Series 76 actuators | — |

### Field notes for `ProductCard`
- `ratings[].service_type`: `on_off`, `modulating` or `general` (3-phase table: a single rating, no service split).
- `electrical[].frequency_hz`: `60`, `50` or `null` (24V models: not frequency-specific).
- `phase`: `1`, `3` or `null` (24V AC/DC / DC).

Errors: `401 UNAUTHORIZED`, `404 SESSION_NOT_FOUND`, `422 VALIDATION_ERROR`, `502 LLM_UNAVAILABLE`, `504 LLM_TIMEOUT`,
`503 DB_UNAVAILABLE`. If the agent fails, the user's message is saved but no answer is; retrying with the same
`client_message_id` is safe.

## GET /api/sessions?limit=20&offset=0
```json
{
  "items": [
    {
      "id": "c1d2…",
      "title": "What is the torque of 761A00-11300000/A?",
      "created_at": "2026-11-03T18:20:10Z",
      "updated_at": "2026-11-03T18:21:40Z",
      "message_count": 4,
      "last_message_preview": "It draws 15 W (motor power)…"
    }
  ],
  "total": 1
}
```
Sorted by `updated_at` descending. `title` = first query (60 characters max).

## GET /api/sessions/{session_id}/messages
```json
{
  "session_id": "c1d2…",
  "title": "What is the torque of 761A00-11300000/A?",
  "messages": [
    { "id": "…", "role": "user", "content": "What is the torque of 761A00-11300000/A?", "status": null, "products": [], "suggestions": [], "created_at": "…" },
    { "id": "9a8b…", "role": "assistant", "content": "The **761A00-11300000/A** …", "status": "answered", "products": [ /* ProductCard */ ], "suggestions": [], "created_at": "…" }
  ]
}
```
Errors: `404 SESSION_NOT_FOUND` (it doesn't exist or belongs to another user).

## DELETE /api/sessions/{session_id}
Deletes the conversation with its messages and debug traces. `204` with no body.
Errors: `404 SESSION_NOT_FOUND` (it doesn't exist, was already deleted, or belongs to another user). The mobile app
treats `404` as success when it syncs an offline deletion.

## Debug endpoints (admins only)
All of them require `user.is_admin` (otherwise `403 ADMIN_REQUIRED`) and `DEBUG_API_ENABLED=true` on the backend
(otherwise `503 DEBUG_DISABLED`). They cover **every user's** conversations: the normal `/api/sessions…` endpoints stay
scoped to the caller.

### GET /api/debug/sessions?limit=100&offset=0
Same items as `GET /api/sessions` plus the owner, for all users, newest first (`limit` ≤ 500):
```json
{
  "items": [
    {
      "id": "c1d2…", "title": "What pieces are 220 V?", "created_at": "…", "updated_at": "…",
      "message_count": 2, "last_message_preview": "The following Series 76 models…",
      "user": { "id": "7b0e…", "email": "luis@konecto.test", "name": "Luis Gómez", "is_admin": false }
    }
  ],
  "total": 19
}
```

### GET /api/debug/sessions/{session_id}/messages
Same response as `GET /api/sessions/{session_id}/messages`, for a conversation of any user. `404 SESSION_NOT_FOUND`
if it doesn't exist.

### GET /api/messages/{message_id}/debug
Trace of one answer of any user. `404 MESSAGE_NOT_FOUND` if the message doesn't exist or has no trace.
```json
{
  "message_id": "9a8b…",
  "session_id": "c1d2…",
  "model": "anthropic/claude-haiku-5.5",
  "latency_ms": 2140,
  "usage": { "input_tokens": 3120, "output_tokens": 210 },
  "steps": [
    {
      "type": "tool_call",
      "name": "lookup_actuator",
      "args": { "part_number": "761A00-11300000/A" },
      "result": { "match_type": "exact", "found": true, "results": [ { "base_part_number": "761A00-11300000/A", "onoff_torque_inlb": 700, "…": "…" } ] },
      "duration_ms": 12,
      "error": null
    }
  ],
  "grounding": { "ok": true, "unverified_numbers": [], "retried": false },
  "structured_output": { "status": "answered", "part_numbers": ["761A00-11300000/A"], "alternatives": [], "suggestions": [] },
  "error": null
}
```
Errors: `403 ADMIN_REQUIRED`, `404 MESSAGE_NOT_FOUND`, `503 DEBUG_DISABLED`.

## GET /api/health
`200` → `{ "status": "ok", "db": true, "actuators": 68 }` · `status: "degraded"` if the DB doesn't respond.
